This is a starting point for Go solutions to the
["Build Your Own Shell" Challenge](https://app.codecrafters.io/courses/shell/overview).

Built a POSIX-compliant shell from the ground up to deeply understand shell command parsing, the REPL (Read-Eval-Print Loop) cycle, and the mechanics of process execution. Explored how shells interact with the operating system to run external programs, manage environment variables, process quotes, and implement core built-in commands like `cd`, `pwd`, and `echo` in Go.
